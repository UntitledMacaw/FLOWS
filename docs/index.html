FLOWS

Flood Likelihood from pre-compiled Watershed Analysis

A lightweight flood-risk estimation approach designed to run on modest hardware — using topology-based basin pre-compilation instead of full hydrodynamic simulation.

01

About the Project

Flood-risk estimation can require the integration of several different types of data, including terrain, soil properties, land cover, precipitation, etc. This can become particularly challenging for intense, short-duration rainfall events — where conditions may change quickly and useful estimates may need to be produced within a limited time window.

[ Core Technical Question ]

Can the computationally expensive analysis of terrain topology and storage capacity be precomputed beforehand, so that flood-risk estimation can be generated quickly as soon as new rainfall data becomes available, while accepting some loss in physical fidelity?

Rather than attempting to deal with the full complexity of a hydrodynamic model, FLOWS precomputes the terrain structure and its potential storage relationships, then combines this information with rainfall-derived runoff estimates.

Under an intentionally conservative scenario of high antecedent moisture, the model uses AMC III soil conditions to estimate water accumulation and depth distribution. This preprocessing works by finding bowl-like depressions and their contributing areas, where runoff tends to accumulate, and computes:

  • Area:
  • Elevation – Volume Relationship:
  • Geographical Positioning:
  • Composite Curve Number:

Once this data is compiled, rainfall forecasts can be converted into water volumes and handled by our pre-calculated values — shifting most of the computational cost from runtime to a one-time preprocessing stage.

Technical Approach

The methodology breaks down terrain preprocessing into six distinct phases:

Step 01 Find a good DEM

Obtain a Digital Elevation Model (DEM) with acceptable resolution.

Step 02 Basin Identification

Find bowl-like topographic depressions ("basins") across the terrain.

Step 03 Storage Calculation

Compute storage–volume relationships for each basin

Step 04 Infiltration Handling

Incorporate rainfall forecasts and infiltration estimates

Step 05 Water accumulation Estimation (in progress)

Estimate water height and flood risk using pre-calculated data

Step 06 Real World Testing (in progress)

Validate results against real-world historical rainfall and flooding events.

05

Elevation Data

The project uses ANADEM, a DEM produced by Brazil's National Water and Basic Sanitation Agency (ANA) in collaboration with UFRGS — a refined version of Copernicus GLO-30 with reduced vegetation bias, developed specifically for hydrological analysis in South America.

[ Adaptation Warning ]

The data sources and parameters used here were chosen specifically for Brazilian territory. To adapt this project to another region, use an equivalent DEM and soil parameters for your area of study. More on that can be seen on provided documentation.

06

Pipeline Overview (Core Boxes)

Since the full South American DEM exceeds 60 GB in storage, processing is executed in dynamic spatial windows ("core boxes") to prevent memory overflow:

  1. Define a central analysis box (core box).
  2. Clip the terrain with an initial spatial margin (buffer).
  3. Identify basins within that extended margin.
  4. Check whether any basin "belonging" to the core box touches the buffer's edge (indicating an incomplete boundary cut).
  5. If so, increase the buffer margin dynamically and repeat, up to a safety threshold.
  6. If clean, save the result — completely free from tile boundary artifacts.

Whether a basin "belongs" to the core box or "leaked" to the edge is determined by comparing each basin's centroid against the original core box bounds — ensuring every basin is counted exactly once without duplication.
