# FLOWS
Flood Likelihood from pre-compiled Watershed Structure (F.L.O.W.S)

Using ANADEM: A Digital Elevation Model (DEM) brought to life by the Brazilian National Waters and Basic Sanitation Agency (ANA) in colaboration with the Federal University of Rio Grande do Sul (UFRGS). It is a refined version of Copernicus GLO-30, with reduced vegetation bias, available for South America.
